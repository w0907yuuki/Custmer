#アプリ名
  Customer

#概要
　ユーザー管理および顧客（取引先）情報を一元管理するWebアプリです。
  権限管理や認証機能を実装し、業務での利用を想定した設計にしています。
#作成背景
　Java（Spring Boot）の理解を深めることに加え、
  認証・認可などのセキュリティ周りの実装を学ぶために作成しました。
  特に、パスワード管理やアカウントロック機能など、
  実務で求められる機能の実装を意識しました。

#使用技術
　java(spring boot)
　MySQL
  HTML CSS Javascript

#主な機能
　・ログイン機能（認証機能）
　・ユーザー管理機能
　　- 登録 / 編集 / 削除 / 検索
　　- 権限による操作制御（編集・削除の制限）
　・ユーザー登録機能
　　- メールアドレス + ワンタイムパスワードによる認証
　・顧客管理機能
　　- 登録 / 編集 / 削除 / 検索
  
#工夫した点
　・セキュリティを意識した実装
　　- パスワードのハッシュ化
　　- ログイン失敗回数によるアカウントロック
　　- 権限レベルによるアクセス制御
　・検索機能の利便性向上
　　- 複数条件での検索に対応し、柔軟なデータ取得を可能にした
